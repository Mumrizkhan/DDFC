## API Request Lifecycle

```
1. USER INITIATES REQUEST
   ??? Browser: POST /api/v1/auth/staff/login
       Payload: {email, password}

2. AUTHENTICATION LAYER
   ??? Validate: Check AspNetUsers + PasswordHash
   ??? If ?: Get user's roles & claims
   ??? If ?: Return 401 Unauthorized

3. TOKEN GENERATION
   ??? JwtService.GenerateStaffTokenAsync()
   ??? Payload includes:
       • sub, email, name (basic claims)
       • role: "Admin" (from AspNetUserRoles)
       • permission: [...] (from AspNetRoleClaims)
       • custom claims (userType, dept, etc)
   ??? Sign with secret key
   ??? Return token to client

4. PROTECTED REQUEST
   ??? Browser: GET /api/v1/admin/dashboard
       Header: Authorization: Bearer <token>

5. AUTHENTICATION MIDDLEWARE
   ??? Extract token from header
   ??? Validate signature
   ??? Parse claims into ClaimsPrincipal
   ??? Attach to HttpContext.User

6. DEBUG MIDDLEWARE (if enabled)
   ??? Log: Authorization header value
   ??? Log: IsAuthenticated status
   ??? Log: All user claims
       [AuthDebug] Claim: role = Admin
       [AuthDebug] Claim: permission = CanManageUsers
       etc.

7. AUTHORIZATION MIDDLEWARE
   ??? Read: [Authorize(Policy = "AdminOnly")]
   ??? Check: RequireClaim("role", "Admin")
   ??? Find in HttpContext.User.Claims
   ??? If found: ? Continue to controller
   ??? If not: ? Return 403 Forbidden

8. CONTROLLER EXECUTION
   ??? AdminController.Dashboard()
   ??? Return 200 OK with data

9. RESPONSE SENT
   ??? Browser receives dashboard data
```
